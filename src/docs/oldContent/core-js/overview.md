# Overview

Core JavaScript is the foundation for everything you’ll script in Open Sourcerer. This section is a practical, beginner‑friendly guide to the language features you’ll use most often while writing spells and game logic.

## What you’ll find here

- Syntax & Variables: how to write valid code, declare values, and control scope
- Data Types & Collections: strings, numbers, booleans, objects, arrays, maps/sets
- Operators & Expressions: calculations, comparisons, logical checks, and precedence

Each page focuses on:

- What it is: a plain‑language definition and where it shows up in code
- Why it matters: how it affects your spell logic and debugging
- How to use: short, copy‑pasteable examples
- Common mistakes: pitfalls to avoid (with quick fixes)
- Try in code editor: a tiny snippet you can run immediately

## How to use this section

1. Start with Syntax & Variables to learn the building blocks.
2. Read Data Types & Collections to understand how values are shaped and stored.
3. Review Operators & Expressions to make accurate calculations and decisions.

Feel free to skim the summaries at the top of each page and click the links to jump to a specific topic. When in doubt, run the “Try in code editor” snippet to confirm your understanding.
