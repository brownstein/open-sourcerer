# Getting Started Overview

Welcome to **Open Sourcerer**, the spellcrafting adventure where your JavaScript skills power real-time magic. This guide orients new sourcerers by answering three essential questions:

1. **What is this documentation for?**
2. **How should I use it alongside the Open Sourcerer editor?**
3. **Where do I go next as my spells grow more advanced?**

Use this overview as the map of the realm. Each section below links forward to richer detail so you can progress at your own pace.

## Recommended Learning Path

> _If you’re brand new to Open Sourcerer, follow the suggested sequence. Experienced developers can skip ahead to the APIs._

1. **Introduction** – understand the story context and how scripting empowers your caster.
2. **Using the Docs & Editor** – tour the in-game tools, including the code runner, console, and debugger.
3. **Core JavaScript** – refresh fundamentals like functions, arrays, and async patterns.
4. **Spell APIs** – explore the elemental libraries to craft offensive, defensive, or utility spells.
5. **Gameplay Integrations** – connect your code to events, entities, and persistent state.
6. **Reference & Glossary** – bookmark for quick lookups while you experiment.

When you’re ready to dive deeper, the sidebar always highlights where you are and what’s next.
