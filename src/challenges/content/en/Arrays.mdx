# Arrays

Sometimes we don't just want one value at a time and instead group them together. 
Thats where arrays come in. They are indexed from 0 onward, so for example,
the first three elements in an array are given the index 0, 1 and 2.

The following array contains strings of the elements of the world's magic system:
```javascript
['earth', 'fire', 'air', 'ice']
```
Earth is in the 0th index, 'fire' in the 1st index, 'air' in the 2nd and 'ice' in the 3rd.
