# Variables
Variables are references to data. They allow you to reference and re-use data by name.
That data can be any kind of value, from a simple true or false to a fully fledged Object.
A valid variable name starts with an alphanumeric character and does not contain spaces.
Variables are defined using the `var` keyword, and become available in the code after
definition. Referencing a variable that is not yet defined will result in an error.

Let's look at an example:
<ExampleCode>
```javascript
// Define a variable called my_variable and assign its value.
var my_variable = 1;
```
</ExampleCode>
